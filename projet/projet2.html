Projet 02 · Mobile & Cloud

AgendaFamille

L'application qui organise toute la vie de famille : budget, agenda, tâches, courses, repas et documents, synchronisés en temps réel entre les téléphones de chaque membre.

Contexte
Projet personnel, utilisé par ma famille
Plateforme
Android · Web (iPhone, PC)
Stack
React Native · Expo · TypeScript · Supabase
Données
PostgreSQL en ligne, temps réel, sécurité RLS

Le projet

AgendaFamille est la version 2 de mon application Budget Familial. La première version, en Flutter, gardait les données sur un seul téléphone. Je l'ai entièrement repensée pour que chaque membre ait son propre compte et retrouve les mêmes informations, quel que soit son appareil.

Une dépense ajoutée par un parent, un rendez-vous modifié, un article coché dans la liste de courses : tout apparaît instantanément sur les autres téléphones.

Fonctionnalités

  • Comptes et familles : inscription, plusieurs familles par compte, invitation par lien ou code à 6 caractères.
  • Rôles et permissions : administrateur, adulte, restreint, avec des droits réglables (voir / ajouter / modifier / supprimer) pour chaque partie de l'app.
  • Budget : dépenses et revenus par membre, catégories et enveloppes mensuelles, objectifs d'épargne, comparaison sur 6 mois.
  • Agenda : vues jour / semaine / mois, une couleur par membre, événements privés, partagés ou familiaux, anniversaires automatiques.
  • Organisation : tâches attribuées avec priorité et échéance, listes partagées en temps réel, planning des repas qui remplit la liste de courses, projets de vacances.
  • Documents : carte vitale, assurances, garanties… stockés dans un espace privé, visibles seulement par les membres autorisés.
  • Notifications : alertes push quand la famille ajoute quelque chose, et rappels de rendez-vous, de tâches et d'anniversaires.

Architecture

L'app mobile est écrite en React Native avec Expo et TypeScript. Les données sont dans une base PostgreSQL hébergée sur Supabase, qui gère aussi l'authentification, le stockage des fichiers et la synchronisation en temps réel.

La sécurité est appliquée dans la base elle-même (Row Level Security) et non dans l'interface : chaque requête est vérifiée côté serveur selon la famille, le rôle et les droits de l'utilisateur. Des déclencheurs SQL alimentent le fil d'activité et envoient les notifications push via Firebase Cloud Messaging.

L'app Android est compilée dans le cloud avec EAS Build et reçoit ses mises à jour sans réinstallation (EAS Update). La même base de code est publiée en version web pour les iPhone et les ordinateurs.

Interface & expérience

J'ai gardé l'identité de la V1 : codes couleur (vert pour les revenus, rose pour les dépenses, bleu pour le solde, ocre pour l'épargne), cartes arrondies et bouton flottant pour ajouter en quelques secondes. S'y ajoutent un mode sombre automatique et un écran d'accueil qui résume la journée.

De la V1 à la V2 : stockage local → base de données en ligne ; un seul utilisateur → comptes, rôles et permissions par membre ; Android seul → Android et web.
