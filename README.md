# Portfolio — Yanis Gougaud

Portfolio personnel (HTML / CSS / JS, sans framework) : présentation & CV, projets, compétences et contact.

## Structure
- `index.html` — accueil
- `styles.css` — design commun (couleurs de chaque section dans `:root`)
- `site.js` — menu mobile, transitions, animations au scroll
- `presentation/` — présentation, parcours et CV
- `projet/` — liste des projets + une page par projet (`projet.css`, `lightbox.js`)
- `competences/` — compétences (vue cartes + mode terminal)
- `contact/` — coordonnées et formulaire (ouvre la messagerie)
- `asset/` — CV en PDF (et `photo-profil.jpg` si ajoutée)
